# Synology NVIDIA GPU Monitor 0.6.2

> Screenshot of the current UI. Driver and GPU values in the image are examples from the test device, not package requirements.

![NVIDIA GPU Monitor dashboard and nvidia-smi console](https://raw.githubusercontent.com/PeterSuh-Q3/syno-gpu-monitor/main/docs/nvidia-gpu-monitor.png)

Read-only NVIDIA GPU telemetry monitor for Synology DSM.

- DSM main-menu floating monitor
- GPU utilization history graph and VRAM telemetry
- NVENC/NVDEC utilization, temperature, fan speed, and clock rates
- NVIDIA NVML-based data collection
- No persistent telemetry daemon

This package is rebuilt from the tested NVIDIA Monitor implementation and is now maintained in the unified `syno-gpu-monitor` repository.

# Synology NVIDIA GPU Monitor 0.6.2 (한국어)

> 위 캡처의 드라이버 버전과 GPU 값은 실기 예시이며 패키지 설치 조건이 아닙니다.

Synology DSM용 읽기 전용 NVIDIA GPU 텔레메트리 모니터입니다.

- DSM 메인 메뉴에서 여는 플로팅 모니터
- GPU 사용률 이력 그래프 및 VRAM 텔레메트리
- NVENC/NVDEC 사용률, 온도, 팬 속도, GPU·메모리 클럭 표시
- NVIDIA NVML 기반 데이터 수집
- 상주 텔레메트리 데몬 없음

검증된 NVIDIA Monitor 구현을 다시 패키징했으며, 이제 통합 `syno-gpu-monitor` 저장소에서 유지 관리합니다.
